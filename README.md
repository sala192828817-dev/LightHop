# LightHop
Light Hop — O server hopper mais limpo e rápido. Encontre servidores com o melhor ping, veja players e FPS em tempo real. Ordene por Menor Ping, Menos Players ou Mais Players. Botão Auto Hop te leva automaticamente pro servidor mais estável. Interface moderna com tema amarelo. Pare de entrar em servidor lagado. Escolha o melhor com um clique.
